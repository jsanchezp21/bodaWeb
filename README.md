# Web de boda - Andrea & Jesús

Proyecto web personalizado para la boda de Andrea y Jesús.

## Incluye

- Web pública responsive para móvil, tablet y ordenador.
- Portada con foto principal.
- Animación inicial con corazón dibujándose.
- Cuenta atrás hasta el 29 de agosto de 2026 a las 18:00h.
- Información de ceremonia y celebración.
- Carrusel de fotos.
- Formulario RSVP para invitados.
- Panel privado de administración.
- Exportación de respuestas a Excel.

## Datos principales

- Pareja: Andrea & Jesús
- Fecha: 29 de agosto de 2026
- Hora ceremonia: 18:00h
- Ceremonia: Basílica de la Macarena
- Celebración: Hacienda de Orán

## Estructura

- `backend/`: API Node.js + Express + MongoDB.
- `frontend/`: Angular standalone.
